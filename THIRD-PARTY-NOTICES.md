# Third-party notices

This repository was initialized after reviewing several MIT-licensed open-source Microsoft Entra projects for architectural patterns and interoperability ideas:

- EntraObjectInspector — snapshot/offline boundaries, Graph transport reliability, evidence/coverage discipline, semantic comparison and telemetry patterns.
- Identity Atlas — graph-native node/edge/evidence modeling and interactive topology concepts.
- EntraOps — privilege classification concepts, transitive relationship handling and BloodHound/OpenGraph interoperability patterns.

The initial EntraTopology implementation uses its own naming, public API and topology contracts. If source code is later copied or materially adapted from any upstream repository, retain the upstream MIT copyright/license notice for the affected code as required.
